# 图片分组与硬性格式规则

> 本文件配合 SKILL.md 的"创作流程"使用，是"用户给主题、上传15～20张图"这个具体工作流的操作细则。这里的规则是硬性的（可以客观判断有没有做到），跟其他文件里"风格建议"性质的内容不同，没有灵活空间，每篇必须100%遵守。

## 一、图片通览与分组方法

1. 收到全部图片后，先通览一遍，识别贯穿全文的"核心单品"（比如阔腿裤、卡其裤、亚麻衬衫、一双凉鞋）。
2. 按"变量"给图片分组。变量是图片本身呈现出的差异维度，常见的变量类型：
   - 搭配的另一件单品不同（同一条阔腿裤，搭配凉鞋/牛仔上衣/西装分别成组）
   - 颜色不同（同一件衬衫，蓝/粉/黄分别成组）
   - 场合或风格不同（同一个单品，通勤穿法/度假穿法分别成组）
3. 每一组对应全文的一个小标题，小标题命名格式固定为"核心单品＋变量单品"，例如"阔腿裤+凉鞋""卡其裤+蓝衬衫""亚麻+衬衫"。这个命名法和S姐范文库里的小标题命名习惯（如《卡其裤+蓝衬衫，简单且高级》一文里的"卡其裤+不同蓝衬衫"）完全一致，不要另创新的命名方式。
4. 每组通常是3～7张图片，对应正文的一个独立小节。

## 二、"时尚随笔" vs "图片说明文"：这是本流程质量的生死线

**图片说明文（禁止这样写）**：把每张图当成独立单元，逐张写一句孤立的描述，句子之间没有承接、没有对比、没有情绪起伏，读者可以打乱这些句子的顺序而不影响理解，因为它们互相之间没有逻辑关系。这是最容易掉进去的陷阱，尤其"看图写字"这个动作本身很容易让人下意识地变成"看一张、写一句、看下一张、再写一句"的流水线操作。

反面示例（禁止这样写）：
```
浅蓝色衬衫搭配浅卡其裤，看起来很清爽。【图01】
中蓝色衬衫搭配卡其裤，比较有质感。【图02】
深蓝色牛仔衬衫搭配卡其裤，很有学院风。【图03】
```
问题：三句话互相独立，没有一句是"承接上一句"或"呼应全组主题"的，读起来像产品参数表，不是文章。

**时尚随笔（必须做到）**：小节开头先给一句不针对任何单张图的框架性观点或感受，把整组图片要传达的核心态度立住；然后把图片当作论据穿插在行文里，句子之间要有承接、递进、对比关系；不是每张图都要同等篇幅，该多写的多写，该一句带过的一句带过。

正面示例（参考这样写）：
```
蓝衬衫的选择远比想象中丰富，浅、中、深三种蓝调，能把同一条卡其裤穿出完全不同的性格。
如果偏爱清透文雅的形象，婴儿蓝这种浅色调最养眼，搭配浅卡其在视觉上有种淡淡的高级感。【图01】
中蓝色则更有质感，比浅蓝耐看，比深蓝好驾驭，不管配哪种卡其裤，都透着一股知性潇洒。【图02】
若还想要点学院气，一件蓝色牛仔衬衫最合适，顺便还能把卡其裤调动得更年轻。【图03】
```
对比：第一句是不针对任何图片的框架句，后面三句每句都承接"蓝调深浅"这条线索递进展开，读起来是一段完整的思考，不是三条互不相干的标签。

**自查方法**：写完一个小节，把里面的句子顺序在脑内打乱重新排列，如果读起来完全不影响理解，说明写成了"图片说明文"，需要重写，加入承接句、对比句、总起句，把独立的描述串成一段真正的文字。

## 三、图片标记规则

1. 标记格式固定为 `【图XX】`（中文方括号，两位数字，不足两位前面补0，比如第3张图写作【图03】）。
2. 标记位置：写完一段与该图片相关的文字后换行，独立一行写【图XX】，不要写在句子中间。
3. **编号必须等于用户上传时的原始顺序，不能重新编号**。举例：用户按1到20的顺序上传了20张图，其中第5、第12、第17张被分到"阔腿裤+凉鞋"这个小标题下，正文里讨论这三张图时，标记必须写【图05】【图12】【图17】，不能因为这是本小节内讨论的第一、第二、第三张图，就写成【图01】【图02】【图03】。
4. 开篇部分（纯文字部分）不能出现任何【图XX】标记，第一次出现【图XX】应该在正文第一个小标题开始之后。

## 四、破折号禁令

**全文任何位置都不能出现破折号"——"。** 原来习惯用破折号表达的停顿、转折、解释、总结，改用下面几种方式替代：
- 需要停顿转折：拆成两句话，用句号分开。
- 需要解释说明：用冒号，或者用括号。
- 需要强调总结：直接换一句独立的短句收尾，不借助这个标点制造停顿感。

写完之后，通篇搜索一遍"——"，确认为零处再交稿。

## 五、多人物图片处理：聚焦法 / 共鸣法，二选一

当某一张图里出现2个及以上的人物/穿搭时，必须用下面两种方法之一处理，**禁止"左边……右边……"或"第一位……第二位……"这种逐一对称拆解的写法**（这种写法本质上还是"图片说明文"的变体，只是从"多张图各写一句"变成"一张图里的多个人各写一句"，同样是并列罗列，没有主次、没有取舍）。

### 方法一：聚焦法
挑图里最有代表性、最贴合本小节论点的一套造型，详细展开写（当成主角来写）；另一套只用半句话带过，不单独展开。

示例：
```
这条正红色连衣裙足够饱满张扬，穿上就是人群中最鲜明的那一个身影，无论是剪裁还是这种大气端正的红调，都值得单独拥有一件；旁边那条酒红色的，则更适合想低调一点的姐妹。【图08】
```

### 方法二：共鸣法
先用一句话点出两套造型共同的气质/态度（把两人放在同一个立意下），然后只详细展开其中一套，另一套点到即止、不再单独描写。

示例：
```
两条裙子红得深浅不同，骨子里却是同一股"今天就要美一次"的松弛底气：这条正红色的，足够饱满张扬，穿上就是人群中最鲜明的那一个身影。【图08】
```

两种方法选哪个，取决于图片本身：如果两套造型差异明显、有主次之分，用聚焦法；如果两套造型气质相通、更适合强调共性，用共鸣法。**只能选一个，不能两个都用，也不能把两套造型都展开写。**
