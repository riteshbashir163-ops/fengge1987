# 零AI痕迹自检清单

> 成稿后，逐条对照下面12项自查。任何一项没做到，回去改那部分，不要带着问题交稿。这12条是从S姐真实范文与典型AI生成穿搭文的系统性对比中总结出来的，每一条都对应一个具体的、可检查的写作动作，不是抽象要求。

## 逐条自查

**1. 过渡词检查**
□ 有没有出现"首先/其次/此外/总而言之"这类书面说明文连接词？
→ 有的话，改成"总之/只是/不过/其实/所以说"这类口语化过渡。

**2. 篇幅配平检查**
□ 各小节篇幅是不是被无意识写得差不多长？
→ 检查是否有些点其实该多说、有些点该一句带过，故意打破均匀感。

**3. 真实体感检查**
□ 全文有没有至少一处"暴露不完美/真实体感"的句子（自嘲、身材焦虑、个人偏好、执行上的小尴尬）？
→ 没有的话，在合适的地方加一处，这是人设"活起来"的关键。

**4. 主观断言检查**
□ 有没有用"芸姐觉得""芸姐更建议""芸姐比较偏爱"这类可能被读者反对的主观断言句？
→ 如果只写了"仅供参考""因人而异""大家可以根据自己情况选择"这类免责式表达，改成明确的个人判断句。

**5. 数字具体性检查**
□ 引用的功效/知识点是不是具体数字（比如"是羊毛的5倍""含18种氨基酸""凉快3～4℃"），而不是"更加""明显""显著"这类模糊词？
→ 用具体、略带细节的数字替换模糊表达（数字不必逐一查证学术来源，但要写得像"记得住的常识"，不要写成正式论文式的严谨引注）。

**6. 文化引用具体性检查**
□ 如果引用了电影/名人/文化典故，是否具体到了导演/角色/某个画面细节，而不是"很多电影里都有类似元素"这种泛泛而谈？
→ 没有具体细节的引用，要么补充细节，要么删掉换成别的论证方式。

**7. 标点"人味"检查**
□ 全文标点是不是太规整、太对称？
→ 适当保留一点不完美：允许不完全对称的省略号，允许为了强调而重复一次意思相近的表达，不要一味追求"简洁不重复"。

**8. 结构重复检查**
□ 这篇文章的结构（开篇模型、小标题句式、分类数量）是不是跟最近几篇写的一模一样？
→ 如果是，换一种开篇模型或小标题句式，参考 `谋篇结构与开篇结尾模型.md` 里的六种开篇模型和三种小标题句式轮换使用。

**9. 情绪浓度检查**
□ 情绪浓度是不是从头到尾很平均、很克制？
→ 考虑在某一两处"心血来潮"式地拔高到价值观/人生态度，制造情绪起伏，不要全篇匀速。

**10. 网络热词检查**
□ 有没有用到至少1～2个有时代感的网络热词/中英混搭词，且没有加引号解释？
→ 没有的话适当加入（参考 `芸姐人设与语言规范.md` 里的词库），但不要为了用而用，选跟上下文自然贴合的。

**11. 强调式重复检查**
□ 是不是所有句子都追求了"最精简、不重复"？
→ 允许个别地方为了强调而口语化重复（比如"没有任何遮挡，所以起不到任何掩藏作用"这种语义近似重复），这是人类强调式表达的痕迹，不要一律修剪掉。

**12. 图注绑定具体性检查**（如果本篇有配图/配图建议）
□ 每一句图注是否绑定这一张具体的图/画面？换一张图/画面，这句话是否就说不通？
→ 如果这句图注换哪张图都成立（比如"这套搭配很好看，很显瘦"），说明写得太通用，重写成绑定具体细节（谁、什么颜色、什么身材、什么场合）的句子。

## 最终基准

改完这12条之后，问自己一个问题：**如果把这篇稿子混进 `S姐范文库/` 的16篇里，读者能一眼认出这是新写的吗？** 如果答案是"能"，说明还有没改到位的地方，回到清单重新过一遍。如果答案是"不能"，这篇稿子才算真正完成。
