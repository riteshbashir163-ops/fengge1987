# 零AI痕迹自检清单

> **用途说明**：这份清单是用来排查"明显硬伤"的，不是用来把每一句话都反复打磨得"更漂亮"。过度精修本身也是一种AI感的来源，参考 `防AI检测的底层写作原则.md`。也要记住"过关"的定义是"人类读者/编辑读不出来"，不是某个自动化检测工具的具体分数，工具分数仅作参考信号。
>
> 成稿后，先过第一部分的6条硬性格式规则（客观对错，逐条核实），再过第二部分的12条风格自查（从S姐真实范文与典型AI生成穿搭文的系统性对比中总结出来）。任何一项没做到，回去改那部分，不要带着问题交稿。

## 第一部分：硬性格式规则自查（6条，客观判断，不允许有一条不达标）

**0-1. 破折号检查**
□ 通篇搜索"——"，是否为零处？
→ 只要出现一处就必须改，拆成两句话、换成冒号、括号或独立短句都可以，唯独不能保留破折号。

**0-2. 图片编号检查**
□ 文中每一个【图XX】的编号，是否等于该图片在用户上传时的原始顺序？有没有因为写作/分组顺序方便而重新编了号？
→ 逐个核对，编号必须回到用户上传的原始序号，不能按小节内讨论顺序重新编号。

**0-3. 开篇无图检查**
□ 开篇（第一个小标题出现之前）的纯文字部分，是否完全没有出现任何【图XX】标记？
→ 有的话，把图片标记和相关点评挪到对应小标题的正文段落里。

**0-4. 多人物图片处理检查**
□ 有没有出现"左边……右边……"或"第一位……第二位……"式的逐一对称拆解？多人物图片是否用了"聚焦法"或"共鸣法"其中一种，而不是两套造型都展开写？
→ 有对称拆解的话，改成聚焦法（详写一套、半句带过另一套）或共鸣法（一句点出共同气质、只展开一套）。

**0-5. 句式模板化重复检查（实测最容易翻车的一条）**
□ 全文有多张对比图/多人物图时，处理它们的句式和连接词是不是几乎一样，只换了颜色/单品名词（比如反复出现"……；旁边那件……也是/则是……"）？
□ 连续几段的开头方式、句子长度是不是高度接近，读起来像同一个模板填了好几遍？
→ 把每处对比图/每小节的句子开头单独列出来对照，只要发现连续两处以上用了同一种连接词或同一种句子骨架，必须改到明显不一样为止，参考 `图片分组与硬性格式规则.md` 里"硬性警告"一节的具体改法。

**0-6. 中英混搭自然度检查**
□ 全文有没有出现几处自然的中英混搭词？通篇一个都没有，是比较明显的AI信号。
→ 一个都没有的话，回去按 `芸姐人设与语言规范.md` 里的词库找地方自然加进去；但不必凑够固定数量，为了数字硬塞进去、读起来别扭，反而是另一种"过度优化"的破绽，参考 `防AI检测的底层写作原则.md`。

## 第二部分：风格自查（12条）

**1. 过渡词检查**
□ 有没有出现"首先/其次/此外/总而言之"这类书面说明文连接词？
→ 有的话，改成"总之/只是/不过/其实/所以说"这类口语化过渡。

**2. 篇幅配平检查**
□ 各小节篇幅是不是被无意识写得差不多长？
→ 检查是否有些点其实该多说、有些点该一句带过，故意打破均匀感。

**3. 真实体感检查**
□ 全文有没有至少一处"暴露不完美/真实体感"的句子（自嘲、身材焦虑、个人偏好、执行上的小尴尬）？
→ 没有的话，在合适的地方加一处，这是人设"活起来"的关键。

**4. 主观断言检查**
□ 有没有用"芸姐觉得""芸姐更建议""芸姐比较偏爱"这类可能被读者反对的主观断言句？
→ 如果只写了"仅供参考""因人而异""大家可以根据自己情况选择"这类免责式表达，改成明确的个人判断句。

**5. 数字具体性检查**
□ 引用的功效/知识点是不是具体数字（比如"是羊毛的5倍""含18种氨基酸""凉快3～4℃"），而不是"更加""明显""显著"这类模糊词？
→ 用具体、略带细节的数字替换模糊表达（数字不必逐一查证学术来源，但要写得像"记得住的常识"，不要写成正式论文式的严谨引注）。

**6. 文化引用具体性检查**
□ 如果引用了电影/名人/文化典故，是否具体到了导演/角色/某个画面细节，而不是"很多电影里都有类似元素"这种泛泛而谈？
→ 没有具体细节的引用，要么补充细节，要么删掉换成别的论证方式。

**7. 标点"人味"检查**
□ 全文标点是不是太规整、太对称？
→ 适当保留一点不完美：允许不完全对称的省略号，允许为了强调而重复一次意思相近的表达，不要一味追求"简洁不重复"。

**8. 结构重复检查**
□ 这篇文章的结构（开篇模型、小标题句式、分类数量）是不是跟最近几篇写的一模一样？
→ 如果是，换一种开篇模型或小标题句式，参考 `谋篇结构与开篇结尾模型.md` 里的七种开篇模型和三种小标题句式轮换使用。

**9. 情绪浓度检查**
□ 情绪浓度是不是从头到尾很平均、很克制？
→ 考虑在某一两处"心血来潮"式地拔高到价值观/人生态度，制造情绪起伏，不要全篇匀速。

**10. 网络热词自然度检查**
□ 0-6提到的中英混搭词，用得是不是自然，有没有为了"用而用"生硬插入、或者加了多余的引号解释？
→ 每一处都应该像日常说话一样脱口而出，读起来别扭的就删掉或换个更贴合上下文的词，宁可少用也不要硬塞。

**11. 强调式重复检查**
□ 是不是所有句子都追求了"最精简、不重复"？
→ 允许个别地方为了强调而口语化重复（比如"没有任何遮挡，所以起不到任何掩藏作用"这种语义近似重复），这是人类强调式表达的痕迹，不要一律修剪掉。

**11.5 用词偏好一致性检查**
□ 全文的审美评价词是不是为了"避免重复、显得词汇量丰富"，用了一大堆不同的近义词（比如这段用"松弛"、下段特意换成"惬意"、再下段换成"悠闲"）？
→ 反过来做：挑2～4个核心词（参考 `芸姐人设与语言规范.md` 的关键词地图），全文反复回来用这几个词，不要因为怕重复而不断替换。**真人是"用词有偏好、认准几个词反复用"，AI是"追求覆盖面、尽量不重复同一个词"**，这条经常和"避免重复"的直觉相反，容易被忽略。

**12. 图注绑定具体性检查**（如果本篇有配图/配图建议）
□ 每一句图注是否绑定这一张具体的图/画面？换一张图/画面，这句话是否就说不通？
→ 如果这句图注换哪张图都成立（比如"这套搭配很好看，很显瘦"），说明写得太通用，重写成绑定具体细节（谁、什么颜色、什么身材、什么场合）的句子。

## 最终基准

改完以上所有项之后，问自己一个问题：**如果把这篇稿子混进 `S姐范文库/` 的16篇里，读者能一眼认出这是新写的吗？** 如果答案是"能"，说明还有没改到位的地方，回到清单重新过一遍。如果答案是"不能"，这篇稿子才算真正完成。
