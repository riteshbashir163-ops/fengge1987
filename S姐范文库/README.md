# S姐范文库（原始范文 16 篇，请务必先读原文再动笔）

本文件夹保存的是用户提供、用于分析学习的 **S姐时尚穿搭类公众号爆款文章原文 16 篇**，文字与配图均按原文顺序完整保留（共 311 张配图，逐篇对应，一张不少）。

## 使用规则（重要）

> **以后创作S姐风格的文章之前，必须先深度阅读本文件夹里的范文原文，反复模仿其人设、语言习惯、行文结构、开篇/结尾写法、图文配比关系，再动笔写作，不得脱离范文凭空套用通用模板。**

配套的写作方法论总结见仓库根目录的 **[`S姐人设与写作风格深度分析.md`](../S姐人设与写作风格深度分析.md)**——那份文档是从这16篇范文里提炼出的人设画像、语言指纹、结构套路、开篇/结尾模型、图文关系与"零AI痕迹"对照清单。

**正确的学习顺序**：
1. 先在本文件夹里挑 2–3 篇原文，逐句读完，感受真实的语感、节奏、口气（不要只看分析总结，总结会丢失语感这种最难量化的东西）；
2. 再对照根目录的分析文档，理解"为什么这句话这么写、这个结构为什么这样安排"；
3. 写新文章时，主题、句式、图注写法都要能在这16篇里找到"同类项"作为依据，而不是自己发明一套新风格。
